#  Helmet and Number Plate Detection System

An AI-powered Helmet and Number Plate Detection System developed using Deep Learning and Computer Vision techniques. The system detects motorcycle riders, identifies whether a helmet is being worn, and extracts vehicle number plates for traffic monitoring and road safety enforcement.

##  Features

- Helmet Detection using Deep Learning
- Number Plate Detection
- Vehicle Monitoring
- Real-time Image Processing
- Automatic Violation Identification
- User-Friendly Web Interface

##  Technologies Used

- Python
- OpenCV
- TensorFlow / Keras
- HTML
- CSS (SCSS)
- Flask
- NumPy
- Pandas

##  Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/helmet-numberplate-detection.git
```
2. Navigate to the project folder:
```bash
cd helmet-numberplate-detection
```
3. Install dependencies:
```bash
pip install -r requirements.txt
```
4. Run the application:
```bash
python app.py
```
5. Open the application in your browser.

##  How It Works

1. Upload an image or video.
2. The model detects riders and helmets.
3. Number plates are identified and extracted.
4. Results are displayed through the web interface.
